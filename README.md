# One Word, First Thought

A one-word entry for the make.fun bounty "One Word, First Thought". The entry is exactly one word — the first word that comes to mind, with no topic and no second draft: a word about throwing someone out of a window. Surprising, vivid, and funny enough to reward a second look.

> defenestration

## How to run

```bash
node main.ts
```

This writes the entry word to `/output/entry.txt` (no trailing newline).
